## Source corrections and boundaries

### P2 — tracing must not suppress or replay business execution

`dashboard/source-tracing.ts` now guards optional tracing-configuration and `ctx.tracing.enterSpan` property access. It invokes the original business callback through one memoised `runOnce` function across synchronous native callbacks, deliberately broken accessors, throwing thenables and delayed callbacks. A tracing exporter error does not mask the original callback's success or exception. The worker's scheduled handler preserves its `waitUntil` work, even if tracing access throws.

Regression tests: `test/dashboard-source-tracing.test.ts` and `test/dashboard-source-tracing-integration.test.ts`. Faults include throwing `ctx.tracing` getter, throwing `enterSpan` getter, delayed callback after fallback, deferred Promise callback, tracer-side synchronous and asynchronous exceptions, and scheduled `waitUntil` when tracing is disabled or broken.

### P1 — automatic Cloudflare spans have a separate privacy surface

`dashboard/wrangler.toml` and the local-only canary generator set `[observability] redact_query_string = true`; production `[observability.traces] enabled = false` remains unchanged.

**This is not full privacy protection.** Cloudflare's automatic spans can contain `url.full`, URL paths, cache keys, header metadata, storage operations or user-supplied labels. No local custom-span allowlist can censor Cloudflare's automatic spans.

`scripts/audit-native-trace-privacy.mjs` provides a bounded, read-only parser for independent, genuine provider trace exports. It requires both a custom and an automatic span; detects sensitive query/URL, cache, storage, error, header and unreviewed attributes; rejects unexpected span names, private route paths and absent version bindings; reports counts and static attribute names only. It never prints raw attribute **values or attacker-provided attribute keys**. A content pass is explicitly `CONTENT_PASS_NOT_PROVIDER_AUTHENTICATED`, **not approval**.

Regression tests: `test/native-trace-privacy-audit.test.ts`, including deliberately private values and metadata, unreviewed attribute names including attacker-controlled keys, long span names, unexpected path labels, missing automatic/custom spans, source version mismatch and CLI non-disclosure.

**Unclosed production/privacy gate:** no authenticated, independently read Cloudflare-native automatic trace sample has been obtained from the correct Worker. Production collection must remain disabled until correct-account provider evidence, retention/access policy and an isolated preview canary are independently reviewed. Redaction alone is insufficient.

### P1 — arbitrary signed bundle hashes are not source provenance

`scripts/verify-source-bundle.mjs` and `scripts/verify-native-trace-admission.mjs` now require an exact clean Git source, tracked immutable production configuration, correct Worker identity, query redaction, production tracing disabled, pinned Wrangler 4.151.2, two separately generated byte-identical dry-run bundles, a byte-identical single-script provider content response, consistent provider version ID/deployment ID/ETag across pre/post download, and an HMAC-authenticated owner receipt binding **all** those values.

The source checker rejects a production config that names `ayobamih-clawsweeper-status` when the target is the **different** OpenClaw `clawsweeper-status` Worker. Multipart/unknown provider content returns HOLD instead of asserting verification. The live content endpoint returns the **currently active** script; this checker revalidates deployment IDs after the download to reject version races. This does not imply an unsupported API can fetch a historical version's source bytes.

Regression tests: `test/production-tracing-admission.test.ts` with synthetic provider responses and temporary clean repositories. Proven failures include arbitrary validly signed hashes, mismatched bytes, script identity drift, wrong version etag, a changed deployment during download, missing receipts, split traffic, missing redaction, and tracing enabled in release configuration. Positive mock tests are **not genuine provider evidence**.

**Unclosed operational/source gate:** actual production `clawsweeper-status` returns `2ea8790a6c7c455a7f0291857337d58840d0464f`, not the reviewed candidate. A matching, independent source/bundle/provider receipt for the correct OpenClaw account is unavailable. The new candidate must remain on HOLD.
